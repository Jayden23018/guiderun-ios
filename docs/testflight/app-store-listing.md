## 3. 年龄分级问卷

照实回答。下面几题要注意，其余内容类（暴力、色情、赌博、恐怖等）一律选「无」：

| 问题 | 答 | 理由 |
|---|---|---|
| Shared Location（与他人共享真实位置） | 是 | 陪跑员出发后，双方互相看到位置（Apple 2026-11-16 新增的必答题） |
| 消息与聊天 / 用户之间的交流 | 是 | 跑后双方可以互相留言 |
| 用户生成内容 | 是 | 同上，留言是用户写的文字 |
| 医疗或健康话题 | 否 | 只记录步数、步频、爬升，不给医疗建议 |
| 不受限的网页访问 | 否 | App 内只打开自己的隐私政策和用户协议 |
| 广告 | 否 | 无广告 SDK |

## 5. 版本页（1.0）

### 5.1 推广文本（≤170 字，可随时改，不用重新审核；不影响搜索排名，不放关键词）

目前只在深圳开放，每天 07:00 至 21:00 可以开跑。有陪跑员想陪你跑时，你们会先通个电话，商量集合点、路线和配速，确认后再见面。

### 5.2 描述

只写本构建里真有的功能（`docs/pre-launch-checklist.md` §B1，审核指南 2.3）。第一句最重要，商店里不点「更多」只看得到它。改描述要送审，会变的信息（城市、时段）放 §5.1。

```text
助盲跑帮视障跑者预约志愿陪跑员，一起出门跑步。跑者端全程适配 iOS 读屏（VoiceOver），不看屏幕也能完成约跑、确认和求助。

【跑者】
· 选好出发地点、日期和时段，就能发起约跑。常用地点可以收藏，下次直接选。
· 有陪跑员想陪你跑时，先和对方通个电话，商量集合点、路线、配速和牵引方式。陪跑员填好见面安排，你确认后才算约定。
· 陪跑员出发后，App 会念出「正在赶来」「已到达」等进度，你不用盯着屏幕等。
· 跑步中可以随时听里程、时长和配速。跑完生成跑步记录，可以给陪跑员留言，也可以把合得来的陪跑员设为固定搭档。
· 约跑前要设一位紧急联系人。陪跑中按下求助，系统会给这位联系人发短信，并提醒你的陪跑员。

【陪跑员】
· 完成实名和人脸核验、学完必修培训、资质通过人工审核后，才能接单。
· 打开接单开关、保持 App 打开，就能收到附近的陪跑邀请。
· 出发后共享位置，跑者能知道你到哪儿了。

【开放范围】
目前只在深圳开放，可开跑的时段以 App 内显示为准。开始时间要在 30 分钟以后、30 天以内。

【请注意】
求助功能不能代替拨打 110 或 120。遇到紧急情况，请先拨打报警或急救电话。
```
